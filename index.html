YOUTUBE LINK SETTINGS

유튜브가 앱으로 열리나요?

Windows에 YouTube 앱이 설치되어 있으면 Chrome이 YouTube 링크를 자동으로 앱에 전달할 수 있습니다. 브라우저에서 열고 싶은데 앱이 실행된다면 아래 설정을 확인하세요.

  1. Chrome 주소창에 chrome://apps를 입력합니다.
  2. YouTube 앱을 마우스 오른쪽 버튼으로 클릭하여 앱 설정 / 앱 정보를 엽니다.
  3. 지원되는 링크 열기 / 링크 처리(Open supported links) 옵션이 있다면 자동으로 앱에서 열리지 않도록 변경합니다.
  4. SubBridge로 돌아와 유튜브에서 구독 ↗ 버튼을 다시 클릭합니다.

※ 메뉴명 및 제공 여부는 Chrome 버전에 따라 다릅니다. 설정을 변경하면 SubBridge 이외의 YouTube 링크에도 적용될 수 있으며, 브라우저 코드만으로 앱 실행을 완전히 막을 수는 없습니다. YouTube 앱은 삭제하지 않아도 됩니다.

사용 방법

  1. 사이트 운영자가 Google Cloud에서 YouTube Data API v3를 활성화하고 API 키를 설정합니다.
  2. 조회할 상대방의 유튜브 채널 URL을 붙여 넣고 구독 목록을 조회합니다. Google 계정 연결은 필요하지 않습니다. 비공개 구독은 볼 수 없습니다.
  3. 기본 유튜브에서 구독 버튼을 누르면 Chrome/Windows에 설정된 YouTube 링크 열기 방식으로 바로 이동합니다. 원할 때는, 원할 때만 Google 계정 연결 후 바로 구독을 누릅니다.
  4. 바로 구독은 사이트 운영자가 OAuth 클라이언트 ID와 허용 도메인을 등록해야 이용 가능합니다. Google OAuth 동의 화면의 테스트 사용자 제한 또는 검증 정책이 적용될 수 있습니다.

개인 구독 목록을 공개할지 여부는 각 유튜브 사용자가 결정합니다. 구독 동작은 구글이 요구하는 권한과 API 할당량에 따릅니다.
