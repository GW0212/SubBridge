SETUP

API 연결 설정

GitHub Pages에서도 작동하도록 Google Cloud의 브라우저용 자격증명을 사용합니다. 사이트 관리자가 config.js에 설정하면 방문자는 별도 입력이 필요 없습니다.

여기 입력한 값은 이 브라우저의 로컬 저장소에만 보관됩니다. API 키는 공개 클라이언트 자격증명이므로 반드시 웹사이트 HTTP 리퍼러로 제한하세요. OAuth 클라이언트 보안 비밀은 절대 입력하거나 공개하지 마세요.
HELP

사용 방법

  1. 사이트 운영자가 Google Cloud에서 YouTube Data API v3를 활성화하고 API 키를 설정합니다.
  2. 조회할 상대방의 유튜브 채널 URL을 붙여 넣고 구독 목록을 조회합니다. 비공개 구독은 볼 수 없습니다.
  3. 각 채널의 유튜브에서 구독을 눌러 외부에서 구독하거나, Google 계정 연결 후 바로 구독을 누릅니다.
  4. 바로 구독은 사이트 운영자가 OAuth 클라이언트 ID와 허용 도메인을 등록해야 이용 가능합니다. Google OAuth 동의 화면의 테스트 사용자 제한 또는 검증 정책이 적용될 수 있습니다.

개인 구독 목록을 공개할지 여부는 각 유튜브 사용자가 결정합니다. 구독 동작은 구글이 요구하는 권한과 API 할당량에 따릅니다.
