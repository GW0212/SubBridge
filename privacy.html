개인정보처리방침

서비스: SubBridge · 시행일: 2026년 10월 11일 · 운영자 문의: rmsdn1955@naver.com

1. 개인정보처리자 및 문의

SubBridge는 개인 개발자가 운영하는 YouTube 구독 목록 탐색·관리 웹서비스입니다. 서비스 및 개인정보 관련 문의는 rmsdn1955@naver.com으로 접수할 수 있습니다.

2. 처리하는 정보와 이용 목적

SubBridge는 YouTube API Services(YouTube Data API v3)를 사용합니다. 이용자가 입력한 채널 URL 또는 핸들에 대해 공개 채널명, 공개 채널 식별자, 프로필 이미지, 설명, 공개 구독 목록 등의 API 데이터를 조회하며 이를 화면에 표시하고 검색·정렬·CSV 내보내기에 활용합니다.

이용자가 선택적으로 Google 계정을 연결하면 Google OAuth에서 발급한 액세스 토큰을 이용해 승인된 YouTube 계정의 채널 식별정보, 구독 관계 및 구독 목록을 조회하고 이용자가 명시적으로 실행한 구독 추가·취소 요청을 처리합니다. 전체 구독 기능은 이용자의 확인 후 수행합니다. 공개 목록 조회에는 Google 계정 연결이 필요하지 않습니다.

SubBridge는 서비스 이용을 위해 Google 비밀번호를 직접 수집하거나 저장하지 않습니다. OAuth 권한 요청은 Google에서 제공하는 인증 화면을 통해 처리됩니다.

3. 정보의 저장 및 보유 기간

현재 공개된 SubBridge 정적 웹사이트 코드 기준, 구독 목록과 Google OAuth 액세스 토큰은 실행 중인 웹페이지의 메모리에서 사용하며, 브라우저 페이지를 닫거나 새로고침하면 해당 메모리의 값이 초기화됩니다. 토큰은 Google이 제공한 만료 시각이 지나면 다시 인증해야 합니다. 사용자 구독 목록과 OAuth 액세스 토큰을 SubBridge가 별도 서버 데이터베이스에 저장하는 기능은 포함되어 있지 않습니다.

이용자가 선택한 화이트·다크 테마는 브라우저의 localStorage에 저장되며, 이용자가 브라우저 사이트 데이터를 삭제하면 제거됩니다. 조회 결과를 CSV로 내보낸 경우 해당 파일은 이용자 기기의 다운로드 위치에 저장되므로 이용자가 직접 삭제할 수 있습니다.

Google, YouTube, GitHub Pages 및 이용자의 브라우저 등 외부 서비스가 기술적 로그, 쿠키 또는 데이터를 처리할 수 있으며, 이는 해당 사업자의 정책에 따릅니다. SubBridge 운영자가 외부 서비스의 저장 기간까지 직접 통제하는 것은 아닙니다.

4. 제3자 서비스 및 정보 전송

공개 채널 및 구독 데이터 조회와 구독 변경 기능을 제공하기 위해 이용자의 요청이 Google/YouTube API에 전달됩니다. Google OAuth 인증 화면은 Google이 제공하며, 서비스 웹페이지는 GitHub Pages에서 제공됩니다. API 요청에는 이용자가 입력한 채널 정보, 필요한 경우 액세스 토큰, 요청에 필요한 구독 식별정보가 포함될 수 있습니다. SubBridge는 사용자 정보를 판매하지 않습니다.

관련 외부 정책: Google 개인정보처리방침, YouTube 서비스 약관, GitHub 개인정보 보호 안내.

5. 계정 연결 해제 및 데이터 삭제

이용자는 Google 계정 연결 관리에서 SubBridge에 부여한 접근 권한을 철회할 수 있습니다. Google 권한 철회 시 해당 접근 권한에 따른 기능은 더 이상 정상 동작하지 않습니다. 웹페이지를 종료하거나 새로고침하면 메모리에 저장된 토큰과 조회 결과는 초기화됩니다. 테마 등 브라우저에 저장된 값은 브라우저 설정에서 해당 사이트 데이터를 삭제하여 제거할 수 있습니다.

SubBridge가 보유하는 본인 관련 데이터의 열람·삭제 또는 권한 관련 문의는 rmsdn1955@naver.com으로 요청할 수 있습니다. 다만 Google/YouTube 자체에 저장된 구독 관계는 SubBridge 사이트 데이터 삭제만으로 삭제되지 않으며 YouTube에서 직접 변경해야 합니다.

6. 개인정보 보호 및 이용자 권리

SubBridge는 HTTPS로 제공되는 GitHub Pages와 Google API를 사용합니다. 이용자는 서비스 제공 정보에 관해 문의하거나 삭제를 요청할 수 있습니다. 본인 이외의 비공개 구독 정보를 우회하여 수집하지 않습니다.

7. 방침의 개정

서비스의 정보 처리 방법이나 기능이 변경되는 경우 이 페이지를 업데이트하며, 개정 내용은 이 페이지에 공개합니다.
