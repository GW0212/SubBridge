# SubBridge — 유튜브 공개 구독 목록 탐색기

GitHub Pages에서 배포 가능한 정적 웹사이트입니다. 별도 백엔드, npm 설치, 빌드, Render가 필요 없습니다.

## 사이트 기능

- 상대 채널의 **공개 구독 목록** 조회: 50개씩 페이지네이션 (더 불러오기)
- 채널명 검색 · 정렬 · 목록 CSV 내보내기 · 반응형 모바일 UI
- **유튜브에서 구독**: 유튜브의 해당 채널 구독 확인 화면으로 이동 (OAuth 불필요)
- **바로 구독**: Google 계정 OAuth 인증 뒤 YouTube Data API `subscriptions.insert`로 가입 (개별 클릭 후 실행)
- 목록이 비공개라면 접근 불가 (비공개 정보 우회 불가)

## 1. Google Cloud 설정 (관리자 최초 1회)

1. https://console.cloud.google.com/ 에서 프로젝트를 만듭니다.
2. `API 및 서비스 → 라이브러리`에서 **YouTube Data API v3**를 활성화합니다.
3. `API 및 서비스 → 사용자 인증 정보`에서 **API 키**를 생성합니다.
4. API 키에는 **애플리케이션 제한: 웹사이트(HTTP 리퍼러)**를 설정하고, 허용 사이트에 `https://YOURNAME.github.io/*` 를 추가합니다. **API 제한**도 `YouTube Data API v3`로 지정합니다. (본인의 GitHub 사용자명으로 변경)
5. `Google Auth Platform`에서 브랜딩, 대상 사용자(외부), 동의 화면 등의 설정을 완료합니다.
6. **OAuth 클라이언트 ID → 웹 애플리케이션**을 만듭니다. 승인된 JavaScript 원본에 `https://YOURNAME.github.io` 를 추가합니다. **원본에 `/repo-name/` 경로는 넣지 않습니다.**
7. 공개 사용자가 OAuth로 연결하게 하려면 OAuth 앱 게시/검증 관련 Google 요구 사항을 충족해야 합니다. 테스트 상태이면 등록한 테스트 계정만 로그인할 수 있습니다. 구독 관련 YouTube 쓰기 권한은 심사 및 제한이 적용될 수 있습니다.
8. `config.js`의 `API_KEY`와 `OAUTH_CLIENT_ID`에 값을 기입합니다. **OAuth Client Secret은 절대로 웹사이트에 넣지 마세요.**

```js
window.SUBBRIDGE_CONFIG = {
  API_KEY: 'YOUR_RESTRICTED_BROWSER_API_KEY',
  OAUTH_CLIENT_ID: '123456789-abcdef.apps.googleusercontent.com'
};
```

**중요:** 이 버전은 운영자가 `config.js`에 발급 정보를 미리 입력한 버전입니다. 방문자는 인증 정보를 입력할 필요가 없으며 설정창은 제거되었습니다. 그러나 GitHub Pages의 자바스크립트와 네트워크 요청은 공개되므로 API 키와 OAuth 클라이언트 ID 자체는 기술적으로 노출됩니다. API 키에 HTTP 리퍼러 및 YouTube API 제한을 반드시 설정하고 사용량을 확인하세요.

## 2. GitHub Pages 배포

1. ZIP 압축을 풀어 나온 `index.html`, `style.css`, `app.js`, `config.js`, `favicon.png`, `README.md`를 GitHub 저장소의 **루트**에 업로드합니다. (상위 폴더를 추가로 만들지 않음)
2. GitHub 저장소에서 `Settings → Pages → Build and deployment → Deploy from a branch`, `main` / `/(root)` 를 선택하고 저장합니다.
3. 사이트 URL `https://YOURNAME.github.io/REPO/`로 접속합니다.
4. `config.js`가 설정되면 공개 URL을 아는 누구나 목록 조회를 사용할 수 있습니다(키 사용량/할당량 내). OAuth 게시 및 검증 조건을 충족하면 방문자의 Google 계정 연결도 가능합니다.

## 3. 로컬 테스트

- `index.html` 더블클릭으로 화면을 볼 수 있지만, OAuth 로그인은 `file://`에서 작동하지 않습니다.
- 실제 API 사용 테스트는 GitHub Pages의 HTTPS 주소 또는 허용 원본으로 등록된 localhost 웹서버에서 하세요.

## 4. 사용 방법

- 유튜브 채널 URL (`https://www.youtube.com/@handle`, `/channel/UC...`, `/user/name`) 또는 `@handle` 입력.
- `/c/맞춤이름` 또는 개별 영상 URL은 채널을 명확히 식별하지 못하므로 지원하지 않습니다. 해당 채널의 `@핸들`을 사용하세요.
- 비공개 구독 목록을 강제로 가져올 수 없습니다. 구독 수가 많으면 아래의 **다음 채널 더 불러오기**를 선택하세요.
- 직접 구독은 해당 계정에서 OAuth를 승인해야 하며, Google/YouTube가 승인한 권한·정책·쿼터에 좌우됩니다.

## API 및 주의사항

- `channels.list`(채널 식별) / `subscriptions.list`(공개 구독 조회 또는 본인 구독 확인) / `subscriptions.insert`(본인 계정의 직접 구독)를 사용합니다.
- `subscriptions.insert`: 공식 문서 기준 **요청당 50 quota units**. 일일 기본 프로젝트 쿼터 및 추가 심사가 제한이 될 수 있습니다.
- 본인 구독 여부 표시는 초기 조회 최대 1,000개로 제한해 API 남용을 막습니다. 1,000개 초과인 경우 실제로 이미 구독 중인데도 버튼이 '바로 구독'으로 남을 수 있으며, 중복 구독 시 오류를 처리합니다.
- 토큰은 페이지 메모리에만 저장합니다. 비밀번호나 OAuth 클라이언트 보안 비밀은 수집하지 않습니다.
- API 키 및 OAuth 클라이언트 ID는 공개 사이트에서 숨길 수 없습니다. OAuth 클라이언트 ID는 공개 값이며 OAuth 동의/원본 제한으로 보호합니다.
- 공식 서비스와 관계없는 서드파티 도구입니다.

공식 문서:
- https://developers.google.com/youtube/v3/guides/implementation/subscriptions
- https://developers.google.com/youtube/v3/docs/subscriptions/list
- https://developers.google.com/youtube/v3/docs/subscriptions/insert
- https://developers.google.com/identity/oauth2/web/guides/use-token-model

## 테마 변경
- 기본 테마는 화이트입니다. 상단 다크 모드 버튼으로 화이트/다크 전환이 가능합니다.
- 선택 테마는 브라우저 로컬 저장소에 유지됩니다. 이전에 선택한 경우 해당 선택을 유지합니다.
- 시작 화면의 큰 소개 배너는 제거하여 바로 채널 검색 영역이 보입니다.

## 이 버전의 사용 안내

- GitHub 저장소에 7개 파일을 그대로 업로드하면 되며, 기존 파일을 덮어쓰세요.
- API 키와 OAuth 클라이언트 ID는 `config.js`에 사전 설정되어 있습니다. 방문자에게 인증값 입력창은 표시하지 않습니다.
- 보안 주의: 공개 GitHub Pages의 소스에 설정값이 들어 있으므로 다른 사용자가 개발자 도구 등으로 값을 알아낼 수 있습니다. 절대 비밀 보관이라고 설명하면 안 됩니다.
- OAuth 로그인은 테스트 계정 제한 및 Google 검증 조건에 따라 이용 가능합니다.


## v2 사용성 변경
- 공개 구독 목록 조회, 검색, CSV, 유튜브에서 구독은 Google 계정 연결 없이 동작합니다.
- Google 계정 연결은 **바로 구독** 기능을 사용할 때만 선택적으로 필요합니다. 상단 `?`에서 설명을 확인할 수 있습니다.
- URL 입력란 아래 `초기화` 버튼은 입력 문자열만 지우며 기존 검색 결과는 유지합니다.
- 구독 카드의 기본 버튼은 `유튜브에서 구독`입니다.
- 정적 GitHub Pages의 config.js에 들어 있는 API 키는 방문자 개발자 도구로 확인 가능합니다. 반드시 API 키의 웹사이트/YouTube API 제한을 적용하세요.


## UI 업데이트
- 구독 채널 리스트 검색창을 데스크톱 가로 공간에 맞게 확장했습니다.
- 기본 순서 정렬 메뉴는 검색창 오른쪽에 고정합니다.
- 채널 검색 돋보기 아이콘을 SVG로 교체하여 세로 중앙 정렬했습니다.
- 모바일에서는 검색창을 전체 폭으로, 정렬 메뉴와 카운터를 다음 줄에 배치합니다.


## 전체 공개 구독 목록 자동 조회 (이번 수정)

- YouTube Data API는 한 번의 호출에서 최대 50개를 반환합니다.
- 채널 URL 조회 시 `nextPageToken`이 없어질 때까지 자동으로 다음 페이지를 불러옵니다.
- 진행 중에는 누적 불러온 개수와 조회한 페이지 수를 표시합니다.
- API 제한/네트워크 오류가 나면 이미 불러온 목록을 남기고, 이어서 불러오기 버튼을 표시합니다(재시도 가능한 토큰이 있는 경우).
- 검색, 정렬, CSV 내보내기는 불러온 목록 기준이며 완료 전에는 일부만 보일 수 있습니다.
- 비공개 구독 내역은 제3자가 볼 수 없습니다. 본인이 로그인하여 `mine=true`로 조회하는 별도 기능이 아닌 한 비공개 항목을 강제로 노출시킬 수 없습니다.


## YouTube 링크 열기 방식

- 각 채널 카드의 **유튜브에서 구독 ↗** 버튼은 별도의 선택창 없이 즉시 YouTube 링크를 엽니다.
- 앱 또는 웹사이트 중 어디에서 열리는지는 Chrome 및 운영체제의 링크 처리 설정에 따릅니다.
- Windows Chrome에 YouTube 앱(PWA)을 설치한 경우 `chrome://apps`에서 YouTube 앱의 링크 처리 설정을 변경할 수 있습니다(버전별 메뉴는 다를 수 있음).
- 목록 제목 오른쪽 `?` 버튼에서 해당 설정 방법을 확인할 수 있습니다.
- 사이트에서 Chrome의 링크 처리 정책을 강제로 우회하지는 못합니다.

## 이 버전 수정
- 앱/웹사이트가 모두 앱으로 열리던 문제에 대응하여 웹사이트 모드를 현재 탭 이동으로 변경했습니다. 앱 모드는 새 창으로 유지합니다.
- 브라우저/운영체제의 앱 연결 설정을 웹사이트 코드만으로 강제 변경할 수는 없습니다.


## 구독 채널 리스트의 ? 도움말
목록 제목 오른쪽 물음표 버튼에서 Windows/Chrome의 YouTube 앱 링크 자동 연결 해제 방법을 확인할 수 있습니다. 팝업은 확인, X, ESC 또는 배경 클릭으로 닫을 수 있습니다. Chrome 버전에 따라 관련 설정이 없을 수도 있습니다.

## 다크모드 배경 수정
페이지 하단의 가로 색상 경계를 제거하기 위해 html과 body에 일관된 배경색 및 최소 화면 높이를 적용했습니다. 기존 기능과 UI는 유지합니다.


## 구독 취소 후에도 목록에 남는 경우
- 새로고침 버튼은 모든 페이지를 서버에 재요청하고 브라우저 캐시를 사용하지 않습니다.
- **다른 사람의 채널**을 조회했다면 내 계정에서 구독을 취소해도 상대방의 구독 목록에서는 삭제되지 않습니다.
- **내 채널**을 조회했고 Google 계정을 연결했다면 채널 ID가 일치하는 경우 `mine=true`로 인증된 실제 내 구독 목록을 조회합니다.
- 구독 취소 직후 YouTube Data API 자체의 데이터 반영이 지연될 수 있습니다. 시간 경과 뒤 다시 새로고침하세요.
- 계정에 여러 YouTube 채널이 연결된 경우 인증된 계정의 채널을 명확히 판별할 수 없어 공개 조회를 유지합니다.


## 본인 구독 해지 반영 확인
- **내 구독 목록 조회**를 클릭해 Google 인증을 완료합니다. 이 버튼은 `subscriptions.list?mine=true`를 이용합니다.
- 상단 URL 입력 후 조회는 상대방의 **공개** 구독 목록을 조회합니다. 본인이 구독을 취소해도 상대방의 구독 목록에서 제거되는 것은 아닙니다.
- 구독 취소 후 '새로고침'을 눌러 확인하세요. 브라우저 캐시는 사용하지 않지만 YouTube 서버의 반영 지연은 제어할 수 없습니다.
- Google 계정에 여러 YouTube 채널이 있다면 OAuth에서 선택한 채널을 확인하세요.


## 새로고침 개선
- 새로고침 시 API의 모든 페이지를 `cache: no-store`로 다시 조회합니다.
- 새 데이터를 모두 받기 전까지 기존 목록을 유지합니다. 성공한 경우에만 일괄 교체합니다.
- 변경된 구독 채널(추가/삭제) 수를 표시합니다.
- Google 계정으로 내 구독 목록 조회 시 인증된 `mine=true`를 사용합니다.
- 다른 사람의 공개 목록은 여전히 공개 데이터만 조회할 수 있으며, YouTube 서버의 최신 데이터 반영 지연은 웹사이트가 강제로 해결할 수 없습니다.


## 변경사항 확인 모드 안내
- **유튜브 채널 찾기(URL)**: 입력한 채널의 공개 구독 정보를 조회합니다. 본인이 다른 계정에서 구독/취소한 내역을 보여주는 기능이 아닙니다.
- **내 구독 목록 조회**: Google OAuth로 선택한 YouTube 계정의 목록을 `subscriptions.list(mine=true)`로 요청합니다.
- **새로고침**: OAuth 연결된 본인 채널이 URL로 열려 있다면 본인 목록으로 전환해 다시 조회합니다. 그렇지 않으면 공개 목록으로 조회하고 안내 메시지를 띄웁니다.
- API 재요청/캐시 우회가 Google YouTube 데이터의 즉각적인 갱신을 보장하지는 않습니다.
- 여러 YouTube/브랜드 계정이 있다면 OAuth에서 실제 변경한 채널을 선택했는지 확인하세요.
