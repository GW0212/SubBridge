# SubBridge — 구독/재생 목록 통합 조회

## 변경 사항
- `유튜브 채널 찾기`의 `구독 목록 조회` 버튼을 `구독/재생 목록 조회`로 변경했습니다.
- 채널 URL을 입력하고 조회하면 **공개 구독 목록과 공개 재생목록**을 순서대로 자동 조회합니다.
- 공개 구독 목록에 접근할 수 없어도 공개 재생목록은 독립적으로 조회합니다. 역방향으로 재생목록 오류가 나더라도 구독 목록은 유지합니다.
- 기존 재생목록 새로고침 버튼, OAuth 기반 내 목록/소유자 조회, 모두 구독, 검색, 구독 취소, 모바일 UI, 정책 페이지는 유지합니다.
- 이 통합 조회는 `subscriptions.list`, `playlists.list`를 각각 호출하므로 개별 조회보다 API 호출 비용이 증가할 수 있습니다. 조회한 항목이 공개되어 있어야 합니다.

## 설치
압축 해제하면 나오는 전체 파일을 GitHub Pages `SubBridge` 저장소 루트에 기존 파일과 교체해 업로드하세요. 배포 후 캐시를 갱신하세요.

## 검증 한계
JavaScript 구문과 ZIP 포함 파일 구조를 검사했습니다. 실제 Google/YouTube API 응답 테스트는 운영자 계정 및 유효한 할당량 없이는 실행하지 않았습니다.


## 재생목록 복사 기능
- 공개 재생목록 카드에서 **내 재생목록으로 복사** 클릭 → 사용자의 명시적 확인 → Google OAuth 계정 연결 → 공개 동영상 조회 → 새 비공개 재생목록 생성 → 순차 추가.
- 원본 재생목록의 구독/저장과 다릅니다. 독립 사본을 생성하므로 원본 업데이트는 동기화되지 않습니다.
- 비공개/삭제/접근 불가능한 동영상은 건너뛰거나 YouTube 서버에 의해 거부될 수 있습니다.
- 원본 조회 중 중단하면 아무것도 생성하지 않습니다. 재생목록 생성 후 중단하면 해당 사본과 복사 완료 동영상은 남습니다.
- 동영상 1개 추가당 50유닛, 재생목록 생성당 50유닛이며 조회에 별도 유닛이 듭니다.
- 정상 작동 여부는 실제 OAuth 계정과 API 잔여 할당량으로 배포 후 검증이 필요합니다.


### 목록 펼침/접힘
- 구독 채널 리스트와 재생목록 리스트는 각각 기본 접힘 상태입니다.
- 접힌 목록에는 반응형 카드 배치 기준 최대 세 줄을 노출하며 목록 내부 세로 스크롤을 지원합니다.
- 펼치기/접기 버튼은 두 목록마다 독립적으로 동작합니다.


## 구독 속도 및 헤더 개선
- 기존 구독 간 고정 950ms 대기를 제거하고 최대 3개의 제한된 동시 구독 요청을 사용합니다.
- 중복 구독은 선조회하여 건너뛰고, 할당량/속도 제한/권한 오류에 신규 요청을 중지합니다. 이미 전송한 최대 3개 요청은 완료될 수 있습니다.
- `구독 채널 리스트` 제목은 한 줄로 표시합니다. 다섯 액션 버튼은 오른쪽 정렬됩니다. 작은 화면에서는 제목 아래에 오른쪽 정렬된 가로 한 줄(필요 시 가로 스크롤)로 표시됩니다.
- 더 빨리 요청한다고 API 사용량이 줄어들지 않습니다. 각 구독 추가는 50유닛이며 YouTube 서버의 제한에 따라 처리량은 달라집니다.


## 2026-10-13 추가 수정 (6종)
- 유튜브에서 구독: 실제 a 링크로 변경하여 휠 클릭/ Ctrl+클릭 새 탭 열기 지원.
- 정렬 목록 마지막에 구독하지 않은 채널 필터 추가: OAuth 계정 연결 후 구독 목록 전체 확인이 완료된 경우만 제공.
- 재생목록 썸네일 전체 표시(object-fit: contain)와 축소형 카드 디자인 유지.
- 구독/재생목록 접힘 안내 문구 제거(내부 스크롤 유지).
- 펼침 버튼의 왼쪽 위치를 각각 기본 순서 선택창, 재생목록 새로고침 버튼의 왼쪽 위치에 맞춤.


## 2026-10-13 UI 개선
- 구독 채널 및 재생목록 리스트 펼치기/접기 버튼을 각각 오른쪽 끝에 고정. 기존 좌측 정렬 계산 코드 제거.
- 카드 및 버튼에 미세한 전환/호버 효과 적용(터치 및 움직임 감소 설정 예외).
- 모바일 2열 레이아웃, 모달 높이, 가로 스크롤 버튼, 좁은 화면의 카드와 썸네일을 정돈.
- API 인증/구독/재생목록 로직은 변경하지 않음.
