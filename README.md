# SubBridge — 검색 강화 / 소유자 구독 취소

GitHub Pages에 7개 파일을 업로드하세요.

- 검색: 채널명·설명·채널 ID를 공백/특수기호에 관계없이 검색하고 한글 초성 검색 지원. 검색어를 띄어쓰기로 분리하면 모든 키워드가 일치하는 채널 표시.
- 구독 취소: **소유자 인증 조회** 또는 **내 구독 목록 조회**로 인증된 목록에서만 버튼이 노출됩니다. 구독 취소 클릭 → 확인 → YouTube subscriptions.delete 호출 → 성공 시 즉시 화면에서 제거.
- 다른 사람의 공개 구독 목록에서는 구독 취소가 불가능합니다. 그 대신 기존 바로 구독 기능을 유지합니다.
- API의 DELETE 요청에는 채널 ID가 아닌 구독 항목 ID가 필요하여 인증 목록을 가져올 때 해당 ID를 같이 저장하도록 변경했습니다.
- YouTube API가 읽기 요청에 대해 이전 데이터를 반환할 수 있으므로, 성공적인 구독 취소 직후에는 자동으로 공개 목록을 다시 불러오지 않습니다.
- 기본 화이트/다크 모드, 모바일 UI, 이전 계정 정보 설정은 유지합니다.

주의: OAuth 권한을 승인한 채널에만 삭제가 적용됩니다. Google 계정 권한이 만료된 경우 재로그인하세요. OAuth 및 실제 API 응답은 배포 후 확인이 필요합니다.

## API 403 오류 처리 보완
- OAuth 요청에도 동일 프로젝트의 API 키를 함께 전달합니다.
- 403 `forbidden`/`PERMISSION_DENIED`를 일일 할당량 소진으로 잘못 표시하지 않습니다.
- 만약 여전히 실패하면 개발자 도구 Response의 `reason` 및 `message`를 확인하세요. 실제 API 오류와 실시간 반영 여부는 배포 후 검증이 필요합니다.
- 정적 배포이므로 API 키는 브라우저에서 볼 수 있습니다. 반드시 HTTP referrer 및 API 제한을 적용하세요.


## API 요청량 최적화
- 새로고침 한 번에 전체 페이지를 한 번만 요청합니다. 변경이 없어도 전체 목록을 재조회하는 1.2초/2.5초 자동 재시도를 제거했습니다.
- 로그인 직후 별도 전체 구독 목록 재조회, 새로고침 완료 후 별도 전체 구독 목록 재조회를 제거했습니다.
- 같은 채널 검색 8초 이내, 동일 목록 새로고침 10초 이내 중복 요청을 막습니다.
- 구독 추가/취소 연속 클릭을 8초 제한합니다.
- 목록 로딩 중 매 페이지 카드 전체 재렌더링을 피하고 완료 후 그립니다.
- 다른 사람의 공개 구독 목록은 계속 마지막 페이지까지 조회합니다.
- YouTube의 서버 측 데이터 전파 지연은 최적화로 제거할 수 없습니다.
- API 키는 GitHub Pages 정적 파일에 포함되어 공개될 수 있으므로 Google Cloud에서 HTTP referrer 및 API 제한을 설정하세요.


## 연결된 구글 계정 관리
- 연결된 상태에서 상단 `✓ 계정 연결됨` 버튼을 누르면 선택창이 열립니다.
- `현재 계정 유지`: 선택창을 닫고 기존 로그인을 유지합니다.
- `다른 계정 연결`: Google 계정 선택 및 권한 동의 창을 다시 엽니다. 인증에 성공한 뒤 이전 계정 전용 데이터와 구독 여부를 초기화합니다. 취소 시 이전 연결을 유지합니다.
- 새 계정으로 연결된 뒤 내 목록은 `내 구독 목록 조회` 버튼을 다시 눌러 확인하세요.


## 모두 구독 기능
- 다른 채널의 공개 구독 목록을 모두 불러온 후 `＋ 모두 구독`을 눌러 사용합니다. 인증된 내 구독 목록에서는 비활성화됩니다.
- 확인창에서 실행 내용과 최대 API 사용량을 확인하고 명시적으로 동의해야 합니다.
- Google OAuth로 연결한 채널의 구독 목록을 `mine=true`로 단 한 번 조회해 이미 구독한 채널은 건너뜁니다.
- 구독 추가는 YouTube 공식 `subscriptions.insert`로 **순차 실행**합니다. 현재 진행률·성공·기존 구독·실패를 표시하고 중단 버튼을 제공합니다.
- 할당량 초과, 인증/권한 오류, 단시간 요청 제한은 즉시 작업을 중단합니다. 에러 후 무제한 재시도하지 않습니다.
- YouTube API는 구독 추가 1건당 50유닛입니다. 예를 들어 미구독 520개라면 26,000유닛으로 기본 10,000유닛/일을 초과합니다. 한 번에 완주를 보장하지 않으며, 일일 한도 초기화 이후 재개하면 이미 구독한 항목은 건너뜁니다.
- 사용자가 해당 화면을 계속 열어 두어야 진행됩니다. 브라우저를 닫으면 작업이 멈춥니다.
- 실제 Google OAuth 및 YouTube API 쓰기 요청을 자동 테스트하지 않았습니다. 배포 후 본인 소수 채널로 확인하세요.

## 새 기능: 재생목록 리스트
- 구독 채널 리스트 아래에 별도 **03 재생목록 리스트** 섹션이 추가되었습니다.
- 조회한 채널에 대해 **재생목록 불러오기**를 클릭하면 `playlists.list` (50개/페이지, 페이지당 1유닛)로 공개 재생목록을 끝까지 불러옵니다. API 사용량 절약을 위해 구독 목록 조회와 동시에 자동 실행하지 않습니다.
- 썸네일, 제목, 설명, 동영상 수 표시, 제목 검색, CSV 내보내기를 지원합니다.
- **유튜브에서 저장 ↗** 버튼은 해당 재생목록 페이지로 이동합니다. YouTube에서 '저장'을 직접 눌러야 합니다. YouTube Data API에는 다른 채널의 재생목록을 내 저장 목록에 추가하는 공식 메서드가 없습니다. `playlists.insert`는 기존 재생목록 저장이 아닌 새로운 재생목록 생성 API입니다.
- 구독 추가/취소, 계정 연결, 테마 기능은 이전과 동일합니다.


## 공개 목록 독립 조회 수정
- URL로 채널을 찾으면 OAuth 연결 여부와 관계없이 공개 구독 목록(`subscriptions.list` + `channelId`)만 조회합니다.
- `내 구독 목록 조회` 또는 `소유자 인증 조회` 버튼을 클릭한 경우에만 OAuth 인증(`mine=true`)이 필요합니다.
- 공개 구독 목록 조회가 거부되어도 채널 정보가 확인되었다면 재생목록 불러오기 버튼을 사용할 수 있습니다.
- 재생목록은 API 키로 `playlists.list`(`snippet,contentDetails`)를 호출하며 인증이 필요하지 않습니다.
- 공개 API가 채널 구독 정보를 거부하거나 비공개로 반환하는 경우 임의로 우회할 수 없습니다.
