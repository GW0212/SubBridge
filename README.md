# SubBridge — 검색 강화 / 소유자 구독 취소

GitHub Pages에 7개 파일을 업로드하세요.

- 검색: 채널명·설명·채널 ID를 공백/특수기호에 관계없이 검색하고 한글 초성 검색 지원. 검색어를 띄어쓰기로 분리하면 모든 키워드가 일치하는 채널 표시.
- 구독 취소: **소유자 인증 조회** 또는 **내 구독 목록 조회**로 인증된 목록에서만 버튼이 노출됩니다. 구독 취소 클릭 → 확인 → YouTube subscriptions.delete 호출 → 성공 시 즉시 화면에서 제거.
- 다른 사람의 공개 구독 목록에서는 구독 취소가 불가능합니다. 그 대신 기존 바로 구독 기능을 유지합니다.
- API의 DELETE 요청에는 채널 ID가 아닌 구독 항목 ID가 필요하여 인증 목록을 가져올 때 해당 ID를 같이 저장하도록 변경했습니다.
- YouTube API가 읽기 요청에 대해 이전 데이터를 반환할 수 있으므로, 성공적인 구독 취소 직후에는 자동으로 공개 목록을 다시 불러오지 않습니다.
- 기본 화이트/다크 모드, 모바일 UI, 이전 계정 정보 설정은 유지합니다.

주의: OAuth 권한을 승인한 채널에만 삭제가 적용됩니다. Google 계정 권한이 만료된 경우 재로그인하세요. OAuth 및 실제 API 응답은 배포 후 확인이 필요합니다.
