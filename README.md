# SubBridge — 소유자 인증 조회 및 공개 목록 갱신 명확화

## 핵심 변경
- 공개 URL 검색은 기존처럼 로그인 없이 조회합니다.
- **소유자 인증 조회** 버튼: 입력한 채널과 OAuth 로그인 계정의 YouTube 채널 ID를 대조합니다. 일치할 경우 `subscriptions.list?mine=true`를 호출하여 인증된 채널의 구독 목록을 전부 페이지네이션합니다. 불일치 시 다른 사람의 정보를 본인 것으로 오인하지 않습니다.
- 이미 소유자 계정으로 로그인한 상태에서 같은 채널을 검색해도 자동으로 인증 조회로 전환합니다.
- 공개 목록과 소유자 인증 목록의 출처를 분명하게 표시합니다.
- 새로고침은 이전 목록을 보존한 채 전체 페이지를 새로 요청하고, 성공 시 한 번에 교체합니다. 강제 새로고침과 브라우저 캐시 우회는 적용되지만 YouTube 서버가 아직 반환하지 않은 구독 변경 사항을 강제로 얻는 방법은 없습니다.
- 기존 UI, 다크/화이트 모드, 모바일, 중앙 알림, CSV, 구독 기능 유지.

## 사용법
1. 기존처럼 채널 URL을 조회합니다.
2. **조회 대상 채널을 실제 운영하는 계정**이라면 소유자 인증 조회를 누르고, 구독을 변경한 동일한 YouTube 채널/브랜드 계정을 OAuth에서 선택합니다.
3. YouTube에서 추가/취소 후 새로고침합니다.
4. 공개 목록만 보는 사람은 `channelId` API가 제공하는 최신 응답까지만 표시됩니다. 로그인 없이 다른 사람의 실제 실시간 구독 상태를 더 빨리 읽는 지원 API는 없습니다.

## 검증 및 주의
JavaScript 문법 검사를 수행했지만 실제 Google 계정 및 YouTube 서버에 접근해 실시간 변경을 확인하지는 못했습니다. OAuth 클라이언트 ID는 공개 식별자이며 정적 GitHub Pages의 API 키는 개발자 도구로 확인 가능합니다. API 키 제한 설정을 권장합니다.
